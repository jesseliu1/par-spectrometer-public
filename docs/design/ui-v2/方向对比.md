## 看图前先知道的几点

这些是 Stitch 生成时带进来的问题，三套都有，选方向时请只看配色、字号、密度和整体气质，不要按这些细节打分：

1. **图里的数字和文字是 Stitch 编的。** 记录 ID、时间、指标数值、单位（如叶绿素加权写成 `rel`、`norm`、`mW/m²`）都不是本产品的数据，单位以规格为准。
2. **Stitch 加了页面要求里没有的内容**，实现时不会照搬：
   - A：「在线 · 探测器就绪」「校验状态 PASS」「波长标定 CAL_…」「导出数据」按钮、导航里的「通信设置」「系统日志」；2 号设备被画成删除线（实际应是正常）。
   - B：「Sensor #GH-402 Active」「CRI 92.4」「正常设定区间内」、曝光列里的「过曝」「断开」、示例库文件名。
   - C：「值班员 02」「固件版本」「通信延迟」「在线 · 探测器就绪」。
   其中「在线」「探测器就绪」和 alpha 的「不连接设备」矛盾；alpha 默认 0 级，不采集、不写设备（S-4）。
3. **主光谱都没画出按波长着色的填充。** 这是 V1.0.x 的辨识特征，`ui-v2-pages.md` 第 3 节要求三套都保留。A、C 画成单色，B 只画了参考曲线、漏了主光谱。实现时按 V1.0.x 的着色方式画，与方向无关。
4. **状态色的用法和规格不一致。** 三屏都把「成功」画成绿色徽标；规格里正常状态用正文色（UI-262），曝光列新单采记录的欠曝光、过曝光与正常同色（D-154）。这部分以规格为准，各方向只换取值。
5. **尺寸。** 要求是 1440×900，Stitch 的画布是 2560×2048，导出图按宽 1440 缩放，所以是 1440×1152，下方多出的空白不代表真实布局。
6. **B 的字体。** Stitch 保存「Greenhouse Field」设计系统时丢掉了字体字段，B.png 的中文标题和数字回退成了衬线字体，按钮里的字也被挤到换行。方向 B 本意是 Noto Sans SC、更大的字号，看图时请忽略衬线和换行。

## 方向 A：实验室仪表

**说明**：浅灰蓝底、白色面板、1 px 细边框、蓝色强调，表格紧凑，数字用等宽字体。Stitch 自动生成的「Precision Radiometry」设计系统和这个方向基本一致，强调色是 `#0284c7`（天蓝），比 V1.0.x 的 `#2563EB` 稍浅。

- **优点**：同屏信息最多，一屏能放下 8 行以上记录、完整光谱和六张指标卡；和 V1.0.x 的配色最接近，老用户几乎不用重新适应；令牌最完整（Stitch 给出了颜色、字号、间距、组件规格），落地成本最低。
- **缺点**：「新版本」的感觉最弱；字号小（正文 13–14 px），强光下或站着看屏幕时偏吃力；指标卡在 1440×900 下高度过大、留白多，实现时要压缩。
- **适合**：办公室、实验室、大屏桌面，用户是熟悉 V1.0.x 的工程和研究人员。
- **与 V1.0.x 的差异**：导航从顶部五个标签页改为左侧竖排；设备选择从顶部公共栏的单选按钮改为下拉加按钮；数字改用等宽字体；去掉了分组框（QGroupBox）的标题框样式，改为无阴影的平面面板；强调色由 `#2563EB` 变为 `#0284c7`（如选 A，建议改回 V1.0.x 的蓝色，保持延续）。

## 方向 B：温室田间

**说明**：暖白底、白卡片、沙色边框、叶绿色主色、大地棕点缀；字号和按钮都更大（正文 16 px，按钮 44 px 高，表格行 40 px，指标值 40 px 粗体），PPFD 卡片突出。

- **优点**：关键读数（PPFD、照度）一眼就能看到；控件大，适合触屏一体机和戴手套操作；暖色底在强光下比纯白刺眼程度低，深色正文对比度高；和「植物光照」的业务语义最贴近。
- **缺点**：同屏信息最少，1440×900 下记录表只能放 8 行左右，详情区 54 项指标和光谱计算页需要更多滚动；绿色主色和「正常 / 成功」的语义容易混，需要在令牌里把强调色和状态色分开；Stitch 稿子质量最差（字体回退、按钮文字换行、主光谱缺失），看图会低估这个方向。
- **适合**：温室现场、触屏一体机、光线强的环境，用户是种植人员。
- **与 V1.0.x 的差异**：整体色调从冷蓝灰换成暖白和绿；控件和字号放大约 1.3 倍；指标卡从紧凑表格改为大卡片；导航改为左侧竖排大图标。改动最大，V1.0.x 用户需要重新熟悉。

## 方向 C：控制室暗色

**说明**：深蓝灰底（`#0F172A`）、深色面板、青色强调，状态栏常驻；数字等宽，表格紧凑，信息密度和 A 接近。

- **优点**：长时间盯屏不刺眼，昏暗环境下光谱曲线和状态色最醒目；密度和 A 相当，信息量不打折；「新版本」的感觉最强。
- **缺点**：截图、打印和导出报告与白底文档不一致；红、琥珀两种状态色在暗底上要专门校对对比度（`ui-v2-pages.md` 3.3 已提出）；按波长着色的主光谱在深色底上需要重新调亮度，否则蓝紫段会看不清；办公室白天环境下观感偏重。
- **适合**：值班监控、昏暗环境、多台设备连续运行。
- **与 V1.0.x 的差异**：从浅色整体改为深色；V1.0.x 没有深色模式，所有颜色（含参考曲线四色）都要换一套取值；导航改为左侧竖排。

## 三套对照

| 维度 | A 实验室仪表 | B 温室田间 | C 控制室暗色 |
|---|---|---|---|
| 同屏信息量 | 高 | 低 | 高 |
| 强光下可读性 | 中 | 高 | 低 |
| 长时间盯屏 | 中 | 中 | 高 |
| 与 V1.0.x 的延续 | 高 | 低 | 中（布局近，颜色全换） |
| 截图 / 报告一致性 | 高 | 高 | 低 |
| 触屏友好 | 低 | 高 | 低 |
| 令牌完整度（本次 Stitch 产出） | 完整 | 只有说明 | 只有说明 |
| 落地成本 | 低 | 中 | 中（要单独校对暗底状态色和光谱着色） |

## 推荐（待负责人选择）

推荐 **A 作为 alpha 的基础样式**，强调色改回 V1.0.x 的 `#2563EB`。理由：alpha.1 先给负责人试用（S-10），首页是历史回放（S-8），这一页的价值在于同屏看清记录、光谱和指标，A 的密度最合适；和 V1.0.x 最接近，试用反馈能集中在功能而不是换皮上；Stitch 已经给出完整令牌，落地最快。

可以考虑的混合：A 的布局密度加上 B 的大号 PPFD 卡片，用在实时概览页（不用于历史回放）。深色模式（C）建议放到 2.0 之后，和 `ui-v2-pages.md` 3.6 第 2 条的推荐一致。
