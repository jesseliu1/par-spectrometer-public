## 2. 各页说明

### 2.1 顶部公共栏与全局状态

- **主要数据**：四个设备位置（名称、正常 / 停用 / 故障 / 未配置），总线状态，采集状态，各设备的异常（设备名、时间、第 N/10 次），全局停止原因。
- **交互**：单选查看设备（切换不弹确认、不改变后台采集范围、跨页保持）；长名称省略、悬停看全名和地址；异常区正常时隐藏；全局停止时弹出说明对话框，「确认」只关闭提示。
- **主要条目**：UI-040～045、UI-137～151、UI-252、UI-253、UI-255～263。
- **新界面要处理的裁决**：DEF-20 / D-152（停用设备停用期间显示灰色「停用」，停用优先）。
- **接口**：API-03、API-04、API-17。

### 2.2 历史回放（推荐第一页）

- **主要数据**：时间范围内最多 500 条记录（序号、ID、采集时间、采集结果、曝光状态）；所选记录的 701 点光谱、四条参考曲线、状态行；详情区 7 组 54 项指标。
- **交互**：编辑起止时间后点「查询」才生效；结束时间不自动推进；超出 500 条提示缩小范围；选中记录时详情和光谱同步；新记录到达时尽量保留当前选中；左侧列表约 40%、右侧详情约 60%，表和图之间的分隔条可拖动；详情宽度不够时退回单列，不缩字号。
- **主要条目**：UI-003、005、006、018～039、046～051、062～071、173、176、177、273～276、287、305～310。
- **新界面要处理的裁决**：DEF-21 / D-154（曝光列：新单采记录的欠曝光、过曝光与正常同色）。
- **接口**：API-05、API-06、API-07、API-08。
- **为什么先做这页**：完全只读，不连设备；用到列表、图表、详情三类最常见的组件，做完这页，其他页面的基础组件就齐了。

### 2.3 光积累计算（DLI）

- **主要数据**：积分周期（日出起算 24 小时）、经纬度、启用时间；PPFD、McCree、叶绿素 A、叶绿素 B 四项的 DLI 曲线、累计值、状态（积分中 / 部分累计 / 有效数据不足）、覆盖时长。
- **交互**：四图两列两行；图外标题左侧名称、右侧累计值；纵轴从零开始；横轴端点和零点完整标注；高度不够时纵向滚动；保存经纬度（写库，后期做）。
- **主要条目**：UI-153、UI-178～185；积分口径 DLI-008～029。
- **接口**：API-10。

### 2.4 光谱计算

- **主要数据**：A、B 各自的「数据库 → 采集记录」；运算法则（加、减、比值）；A、B、结果三张图；采集时间差；四段摘要；完整说明（含案例和参考链接）。
- **交互**：B 默认按 A 的时间自动匹配最近记录（可关闭）；交换 A/B；修改任一输入即作废旧结果；空库显示「无可用光谱」并禁止执行；导出格式选择。
- **主要条目**：UI-155～167、186～251、254、264～270、288～291、314。条目最多，建议拆成「选择与执行」「结果图」「说明与导出」三组 PR。
- **alpha 只读版**（2026-10-18，分支 `ui-v2/web-calc`）：三组合为一个 PR 落地；不做的条目与理由、与 V1.0.3 的差异（D-207 导出目录、D-208 快照作数据库）见该 PR 描述和 `docs/spec/ui-migration-tracker.md` 阶段二表。
- **接口**：API-11～API-14、API-24。

### 2.5 设置与导出

- **主要数据**：导出时间范围与条数预览；总线与设备登记表（含每台设备的「失败停止」开关）；设备状态三行（状态、最近采集与总数、数据库文件与大小）；日志（最近 300 条中最多 50 条）；通信参数配置值与当前值；关于区（LOGO、版本、发布日期、联系方式）。
- **交互**：唯一的「保存」按钮统一保存通信和登记；双击日志打开只读详情；设置页整页滚动；维护入口按钮打开设备维护弹窗。
- **主要条目**：UI-073～105、135、261、279～281、311、312；导出 EXP；配置 CONF。
- **新界面要处理的裁决**：DEF-19 / D-144（非成功状态下也显示最近一次记录的曝光）。
- **接口**：API-15、API-16、API-22、API-23；配置保存属于后期接口。
- **alpha 只读版**（2026-10-18，分支 `ui-v2/web-export`）：只做采集记录导出和配置只读查看；快照不含配置，通信设置与设备登记显示“只读快照不含配置”（D-209）；导出写 alpha 数据目录 `exports/`（D-210）；没有保存、设备维护、选择数据库等写入控件。日志、关于区、维护入口未做，见该 PR 描述和 `docs/spec/ui-migration-tracker.md` 阶段二表。档位 1 起「设备状态与最近日志」与 V1.0.3 一致（状态行取接管状态缓存、日志只读设备库、双击看日志详情，#107）；档位 0 仍不显示。

### 2.6 实时概览

- **主要数据**：当前设备最近一条成功且有光谱的记录：光谱、四条参考曲线、图内核心读数和 20 项指标、六项摘要；记录时间和距今秒数；本轮失败时的提示。
- **交互**：「全部指标」打开与历史详情相同的 54 项；纵轴锁定开关（重启或切换设备默认不锁定）；宽度 ≥1500 像素时摘要六列，否则三列，不缩字号。
- **主要条目**：UI-002、004、009～016、053～061、066～069、168～172、174、175、271、277、278、302。
- **接口**：API-09、API-07、API-08、API-17。
- **alpha 只读快照版**（2026-10-18，分支 `ui-v2/web-overview`）：对快照中每台设备显示最新一条成功光谱记录的摘要卡、状态行（记录时间、距今、曝光、复核）、光谱与图内指标、“全部指标”，顶部固定标注“快照数据，非实时”；不显示采集状态、总线状态、开始/停止（档位 1）。非有限值显示“—”（D-179）；其余边界与未做的条目（参考曲线、默认页等）见 D-211 和 `docs/spec/ui-migration-tracker.md` 阶段二表。

### 2.7 设备维护弹窗

- **主要数据**：硬件错误计数（含「本次新增」）、软件事件；校准参数（5 个节点 + 全局参数）及 PCHIP 预览曲线；通信参数。
- **交互**：在弹窗内选择目标设备；诊断刷新；校准回读、编辑（含拖动预览节点）、写入确认（列出改动）；通信参数写入后核对；退出维护并恢复采集。
- **主要条目**：UI-074、091、092、097、098、106～134、282～286、313；MAINT。
- **新界面要处理的裁决**：DEF-17 / D-134、DEF-23 / D-157、DEF-24 / D-158；裁决 44（重新加入的设备逐台核对，不停掉全部设备）。
- **接口**：全部属于后期接口，需负责人批准。

## 3. 设计方向（待负责人选择）

> 2026-10-18：负责人已选 **A（实验室仪表）**，对比与选定记录见 `docs/design/ui-v2/方向对比.md`。落地（分支 `ui-v2/design-a` 的 `web/src/styles/tokens.css`）与 3.4 草案的差异：`size.kpi` 取 Stitch A 的 22 px（压缩指标卡，不用草案的 28 px）；数值在 `tabular-nums` 之上加等宽字体栈（JetBrains Mono 随包分发，`web/fonts/`，中文回退随包的 Noto Sans SC）。强调色 `#2563EB`（本节草案值）已由负责人 2026-10-18 确认（D-205 裁决 A）。

三套方向共用同一套**状态语义**，只是取色不同。状态色的含义不能因方向不同而改变：

| 语义 | 用在哪里 | 规格 |
|---|---|---|
| 正常 | 正常设备、正常采集 | UI-262、UI-082 |
| 提醒（琥珀） | 等待设备响应、旧记录曝光异常 | UI-300、UI-052 |
| 故障 / 停止（红） | 故障设备、采集停止中、恢复未确认、当前值不一致 | UI-140、UI-145、UI-150、UI-260 |
| 停用 / 未配置（灰） | 停用设备、未登记位置 | UI-259、UI-261 |
| 维护中 | 维护期间的顶栏提示 | UI-097、UI-098 |

四条参考曲线（叶绿素 A、叶绿素 B、McCree、明视觉）在三套方向中都要能和主光谱、彼此之间清楚区分，并保留不同线型（实线、虚线、点线、点划线），不能只靠颜色区分。主光谱沿用 V1.0.x 按波长着色的填充，这是产品的辨识特征。

### 3.1 方向 A「实验室仪表」

- **一句话**：延续 V1.0.x 的浅色蓝灰风格，信息密度高，老用户几乎不用重新适应。
- **适合**：办公室和实验室，大屏，用户已经熟悉 V1.0.x。
- **特点**：白底、浅灰分区线、蓝色强调；数字用等宽数字；表格紧凑；图表网格细而淡。
- **代价**：观感变化最小，「新版本」的感觉弱。

### 3.2 方向 B「温室田间」

- **一句话**：暖白底、绿色主色、更大的字号和点击区域，突出几项关键读数。
- **适合**：温室现场、触屏一体机、光线较强的环境；面向种植人员而不是工程师。
- **特点**：大号 KPI 卡片；PPFD 和 DLI 用大字；表格行高更大；圆角更大。
- **代价**：同屏信息量少，历史回放和光谱计算需要更多滚动。

### 3.3 方向 C「控制室暗色」

- **一句话**：深色背景、青色强调，适合长时间盯屏监测，光谱曲线更醒目。
- **适合**：值班监控、昏暗环境、多台设备连续运行。
- **特点**：深蓝灰底；曲线和状态色在暗底上更突出；状态栏常驻。
- **代价**：打印截图和导出报告时与白底文档风格不一致；暗底上要专门校对红、琥珀两种状态色的可读性。
