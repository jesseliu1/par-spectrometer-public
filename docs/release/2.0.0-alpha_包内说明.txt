PAR 光谱仪专用软件 V2.0 试用版

这是 V2.0 的试用版，供客户试用，不是正式发布版本。使用方法见《PAR 光谱仪 V2.0 试用版 用户手册》。

1. 运行
   把整个 PAR_Spectrometer_2 文件夹解压到本机目录（例如桌面），双击 PAR_Spectrometer_2.exe。
   不要只复制 exe，_internal 和 redist 文件夹都要保留。需要 64 位 Windows 10（1809 或更新）或 Windows 11。

2. 采集
   打开本程序即自动开始采集。第一次打开时还没有登记设备，请在“设置与导出”填写通信设置、登记设备并保存。
   采集期间其他软件不能使用该串口；串口被其他程序（例如旧版光谱仪软件）占用时，本程序不会开始采集，并提示先关闭该程序。
   维护模式（设备维护写入）供工程人员使用，需确认两次才开启。

3. 查看历史数据
   历史回放、光谱计算、导出和光积累计算只显示本程序在这台电脑上自己采集的数据，
   新记录不需要导入即可查到；不显示、也不导入其他软件或其他电脑的数据库。

4. 数据放在哪里
   本版采集的设备库（data\devices\）、日志和本版自己的设置都在 %LOCALAPPDATA%\PAR_Spectrometer_2\，不在程序文件夹里，
   升级到新版本后仍在；本程序不读、不写其他软件的配置和数据库。
   “设置与导出”页底部的“导出诊断包”把日志、配置和维护审计打成 zip，保存在 exports\diagnostics\（不含令牌）；
   同页的“维护记录”列出每次校准写入、通信参数写入与核对（可选列出设备对时）。遇到问题先导出诊断包，再重启或清理。

5. Microsoft Edge WebView2 运行时
   Windows 11 自带；Windows 10 一般已随 Edge 更新安装。首次启动如果提示缺少 WebView2：
   运行本文件夹里的 redist\MicrosoftEdgeWebView2RuntimeInstallerX64.exe 安装（按安装程序的提示确认；本程序不会自动安装），
   装好后重新打开本程序；也可以在提示框里选择“是”，改用本机浏览器打开界面。

6. 卸载
   关闭程序，删除解压出来的 PAR_Spectrometer_2 文件夹和 %LOCALAPPDATA%\PAR_Spectrometer_2\ 即可，电脑上的其他软件不受影响。
   窗口组件（WebView2）每次启动可能在系统临时目录 %TEMP% 留下浏览器缓存文件夹，不含业务数据，可随系统临时文件一起清理。

7. 版本与许可
   版本、构建提交和打包时间见 build_manifest.json；第三方组件许可见 THIRD_PARTY_NOTICES.txt 和 third_party_licenses\。
   本版使用 PySide6 与 Qt 6（LGPL-3.0），不含 PyQt5（S-6）。许可正文与源代码获取方式见 THIRD_PARTY_NOTICES.txt。
